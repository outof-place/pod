# Pod 1.0.0-rc2

The second release candidate for Pod 1.0. Install it by hand from `Pod-1.0.0-rc2.dmg`, also over 1.0.0-rc1: rc2 is signed with a new update key, so rc1's "Check for Updates…" reports that the update feed is improperly signed. Releases after rc2 arrive through "Check for Updates…" again.

Pod needs macOS 27 or later on a Mac with Apple silicon.

## What's new

- **Tabs in the title bar.** A worktree's sessions sit in the title bar, like tabs in Safari. Every tab closes with its × or a middle click, a long row scrolls sideways, and the menu at its end lists every tab. Diffs, files and images open as tabs too. Closing a tab shows the one to its right.
- **Each worktree remembers its last tab.** Switching projects or worktrees brings back the tab you left there.
- **Agent state on tabs, in the sidebar and in Activity.** Each row carries one small mark: a turning ring while an agent works, a bell when it needs you, a green dot for a finish you haven't seen, a red cross for a failure. Finishes you have seen go grey.
- **A calmer sidebar.** One row per project, with the project's icon and its name once, and its other worktrees under it. A branch shows only when it isn't the default one. The line at the bottom appears only while Pod connects or after an error.
- **Project icons and order.** A project shows an icon found in its repository, or one you choose with Change Project Icon…. Drag projects, or use Move Up, Move Down, Move to Top and Move to Bottom, to order them.
- **Hide worktrees.** Hide a worktree from its menu. View › Hidden Worktrees… lists the hidden ones and brings them back. A hidden worktree comes back while its agent waits for you. Hiding only changes this Mac's sidebar, and Pod's cleanup never sees it. Each project also chooses whether worktrees created outside Pod show up.
- **Activity puts "Needs you" first.** Agents waiting for you come first, longest wait first. Then each project gets one section, with finished sessions folded away. The Dock badge counts agents that need you, and notifications say "Claude needs you" with the project and branch under it.
- **⌘-click a file path in a terminal** to open it as a tab at its line and column. ⇧⌘-click opens it in its default app.
- **Links in the browser pane.** Hovering a link shows where it goes, and ⌘-click opens it in your default browser.
- **claude-acc 1.34.1 is built in.** Pod no longer replaces a newer claude-acc with the copy it carries: on one Mac, rc1 replaced claude-acc 1.33.0 with 1.31.15. Pod also stays out of the way once claude-acc has been handed back to Homebrew.

claude-acc's usage moved from the window's toolbar to the menu bar (Pod Menu).

## Removed

- Activity's Group By, Show Unread Only, Show Child Agents, Compact Mode and Show Search options: the new layout covers them, subagents are always listed and the filter is always there.
- The Close Tab toolbar button and the Pod mark with the branch name in the title bar: every tab has its own ×, and the tabs took that row.

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
- **Relative links in the Markdown preview (for example `[x](docs/a.md)`) aren't clickable yet.** Only http, https and mailto links open.
