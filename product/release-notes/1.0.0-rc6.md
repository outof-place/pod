# Pod 1.0.0-rc6

The + starts Claude Code on Opus and a button next to it starts it on Sonnet, you can point at things on a page for an agent and see where it points back, a tab's name is the same everywhere, hidden terminals give their memory back, and iOS simulator apps are ready when an agent leases a device. Linear comes as an experiment, off until you turn it on.

From rc2 to rc5, "Check for Updates…" installs it, and Pod's terminal sessions keep running through the update. From rc1, install it by hand from `Pod-1.0.0-rc6.dmg`: drag Pod into Applications and replace the old one while Pod is still open; the old Pod quits as for an update and leaves the terminal sessions running. rc1's "Check for Updates…" can't install it, because rc2 changed the update key. The DMG is at https://updates.pod.codes/download/v1.0.0-rc6/Pod-1.0.0-rc6.dmg.

Pod needs macOS 27 or later on a Mac with Apple silicon.

## New

- **The + starts Claude Code on Opus, the button next to it on Sonnet.** ⌥⌘T is the + as before. Your own arguments for Claude in Settings › Agents stay; only the model is set. The +'s menu still has the other agents, New Terminal, Choose Agent… and Agent Settings….
- **Co-browse in browser panes.** Mark mode lets you click an element or drag over a region of the page; the agent gets the mark with the element's name, its text and a small screenshot of that spot. An agent can point back at an element or one of your marks (`point --mark <n>`), and you see a ring where it points, also inside frames and scrolled lists.
- **One tab name everywhere.** A name you give a tab shows the same in the native window, Pod's classic window and the CLI, and it stays when the tab's terminal restarts or wakes.
- **iOS simulator apps ready on lease.** A worktree's app (from its recipe) is built once, cached for the next worktree with the same native fingerprint, installed and started with Metro when an agent leases a simulator. A first build that takes longer than Metro's 60 second limit no longer leaves the app on a red error screen: Pod waits for the bundle and opens the app again.
- **Pod looks after Go's build cache.** A small background helper keeps `~/Library/Caches/go-build` within 45 GB, gives space back when the disk runs low, and never deletes what a running build could still read. A switch for it in Settings comes in a later release.
- **Linear, experimental and off by default.** Settings › Integrations › Task tracking has "Linear (experimental)". Turned on and connected with a Linear API key, New Worktree can start from a Linear issue (its name and branch come with it), worktree cards show the issue's state, and a Linear link pasted into the command palette finds its worktrees. The key is kept encrypted in Pod's own data and never shared with Orca.app. Agents reach Linear only after you turn on "Let agents use Linear".
- **Pictures in the terminal.** Hover over a link to an image to see a preview; Command-click and the link menu work under full-screen programs too.

## Changed

- **Hidden terminals give their memory back** and come back with their scrollback when you open them again.
- **The sidebar is quieter.** The "Hiding N discovered worktrees" lines under projects are gone, and worktrees nest under the worktree they were made from, as in Pod's classic window.
- **Prompts Pod sends to an agent are pasted, not typed,** when they are long or carry control characters, so no character in a prompt can act as a key in your shell.
- **New Worktree** picks this Mac or an SSH host to run on, in the native window.
- **Settings** has a project's Source Control AI actions (prompt and agent arguments per action).
- **Split panes** keep their sizes, zoom and focused pane in step with Pod's classic window.
- **Pod's browser for agents:** an agent's larger viewport shows whole in the pane, `viewport --reset` returns the page to its own size, and a tab's browser helper stops after 2 idle minutes.
- **claude-acc 1.38.0:** the janitor no longer trims the Go build cache during builds, and keeps `pnpm store prune` away from installs and heavy jobs.

## Env names in 1.0

- Pod terminals also export `POD_*` aliases of `ORCA_*`. `ORCA_*` stay canonical in 1.0, because the hook scripts, agent configs and plugins Pod shares with Orca.app read them.
- In a terminal's environment a `POD_*` setting wins over `ORCA_*` (orca.yaml, quick commands, launch configs, the env Pod was started with). Pod itself takes `POD_*` settings (tokens, switches, tool paths) once at start.
- Processes that aren't terminals (ACP, codex app-server, agent session hosts) get no `POD_*` aliases in 1.0.
- POD_ names appear in new terminals after Pod's terminal daemon restarts (at the latest after logout or restart).

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
- In a browser pane, clicks don't reach a frame from another site (Electron's offscreen input). Frames from the same site work.
