# Pod 1.0.0-rc5

Developer Tools now reach the programs you start in Pod's terminals, claude-acc 1.36.2 keeps the Go build cache that lint is reading, and the native window takes over Import from Orca, SSH projects and more of Settings.

From rc2, rc3 or rc4, "Check for Updates…" installs it, and Pod's terminal sessions keep running through the update. From rc1, install it by hand from `Pod-1.0.0-rc5.dmg`: drag Pod into Applications and replace the old one while Pod is still open; the old Pod quits as for an update and leaves the terminal sessions running. rc1's "Check for Updates…" can't install it, because rc2 changed the update key.

With Homebrew: `brew install --cask outof-place/tap/pod` for a new install. Installed from Homebrew at rc1, run `brew update && brew upgrade --cask --greedy pod` once; after that, "Check for Updates…" brings later releases.

Pod needs macOS 27 or later on a Mac with Apple silicon.

## Fixed

- **Developer Tools cover Pod's terminals.** With Pod turned on under System Settings › Privacy & Security › Developer Tools, programs started in a Pod terminal now skip macOS's scan of newly built programs, as they would in Terminal: a freshly built test binary starts in about 10 ms instead of 1.5 to 10 seconds. **This takes effect once Pod's terminal service restarts**, for example after a Mac restart. That restart ends the terminal sessions running at that moment, so the update doesn't do it for you: pick a moment when nothing important runs. Until then, terminals work as they did in rc4.
- **claude-acc's janitor keeps Go build cache entries used in the last 90 minutes** (claude-acc 1.36.2). It could delete entries golangci-lint was reading, and lint then failed with "could not load export data".
- **Commands the build scheduler sends to Depot run in the folder they were typed in** (claude-acc 1.36.2), not in the repository's root. `make -C apps/charter-service money-wire` typed at a repository's root failed on Depot with exit code 2.
- Relative and `#heading` links in the Markdown preview open.
- A local shell that exits with an error keeps its pane, with a Restart button that starts a shell again.
- Tidy treats branches merged by squash or rebase as merged, instead of showing them as unpushed work.
- A Command-click on a terminal link to an installer, a certificate, a keychain or anything else this Mac treats as runnable shows it in Finder instead of opening it.

## Changed

- **Claude's status hooks come with each launch.** Pod no longer writes its hooks into `~/.claude/settings.json`; it passes them to each Claude it starts. The entries earlier versions wrote stay while a Claude started before the update still reads them, then Pod removes them once, keeps a backup, and leaves your own entries and comments where they were.
- **Import from Orca:** Settings and the welcome screen find an Orca install, show what would come over, and import it into Pod.
- **Generated tab titles** are on by default.
- **Browser panes:** page zoom and a hard reload, `<select>` menus inside frames, and an account picker for security keys and passkeys.
- **SSH:** add a project on an SSH host and answer its connection prompts in the native window.
- **Settings:** terminal scroll speed and right-click paste, notification mutes per machine, and Pod Workspace's Move In and Move All In, which show what moves before anything does.

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
