# Pod 1.0.0-rc7

The + is a plain + again and starts Claude Code on Opus, with Sonnet in its menu. Pod now sends a prompt to a terminal only while an agent is in front there, so a shell, `sudo`, `ssh` or a REPL can't take a prompt as commands. Orca Mobile, the mobile emulator and voice dictation are gone.

From rc2 to rc6, "Check for Updates…" installs it, and Pod's terminal sessions keep running through the update. From rc1, install it by hand from `Pod-1.0.0-rc7.dmg`: drag Pod into Applications and replace the old one while Pod is still open; the old Pod quits as for an update and leaves the terminal sessions running. rc1's "Check for Updates…" can't install it, because rc2 changed the update key. The DMG is at https://updates.pod.codes/download/v1.0.0-rc7/Pod-1.0.0-rc7.dmg.

Pod needs macOS 27 or later on a Mac with Apple silicon.

## New

- **Settings › Terminal has a theme picker** over Pod's built-in themes, and a link to the terminal's shortcuts. Picking a theme clears the colour overrides made for the old one.
- **⌘J shows your recent tabs** from every worktree while the field is empty, and lists the commands of your plugins.
- **Settings › General** has the ⌃⇥ tab order, whether closing a pinned tab asks first, and this Mac's name as other clients of an SSH workspace see it.
- **Settings › Computer Use** shows the skill and has "Reset Access"; **Settings › Browser** has the Browser Use steps.
- **The browser's "…" menu** opens the page in another browser profile.
- **Welcome** has steps for appearance, integrations and notifications.

## Changed

- **The + starts Claude Code on Opus, and its menu has Claude Code on Sonnet** (⌥⇧⌘T). The separate Sonnet button and the model names next to the + are gone.
- **A terminal whose shell exited keeps its output** and says so, until you press Restart. Return no longer presses Restart.
- **A prompt goes to a terminal only while an agent is in front there.** If a shell, `sudo -s`, `ssh` or a REPL is in front, Pod sends nothing and says why ("Not sent: the agent isn't in front in this terminal"). This holds in the native window, the classic window, chat and SSH panes.
- **A startup line Pod can't type whole** (several lines, control characters, over 512 bytes) is pasted by PodNative instead of typed, and refused where it can't be pasted, such as an SSH host without Pod's relay. Before, part of such a line could run as shell commands.
- The default font is the system font. A saved Geist choice falls back to it.

## Removed

- **Orca Mobile**: the phone app, pairing a phone and the mobile web bundle. SSH to Linux and macOS hosts stays.
- **Orca's mobile emulator**: its Settings page, pane, CLI commands and agent skills. Pod's own iOS simulators stay; an old session's emulator tab opens as "unavailable".
- **Voice dictation** and its ⌘E shortcut: ⌘E now reaches the focused pane. claude-acc does dictation in Pod.
- The "Orca wants to access…" Full Disk Access notice.

## Fixed

- Keep Awake no longer leaves the Mac awake after Pod's runtime crashes.
- An invalid pattern in the terminal's Find finds nothing and says why, instead of failing.
- A closed PodSearch stays closed.

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
- If chat's message reaches the agent but its Enter is refused, the text stays in the agent's input; check it before sending the draft again.
- What you type into a new agent tab before its first prompt arrives can land after that prompt. A fix comes after 1.0.
- On an SSH host, Pod first asks the host's relay whether an agent is in front before it sends a prompt; when the relay hangs, that can take up to 30 seconds.
- Linux SSH hosts get no Pod relay yet, because it isn't packaged: on a Linux host without Node.js you have plain SSH terminals and file access. A fix lands before 1.0.
- In a browser pane, clicks don't reach a frame from another site (Electron's offscreen input). Frames from the same site work.
