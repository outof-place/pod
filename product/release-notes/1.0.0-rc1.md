# Pod 1.0.0-rc1

The first release candidate for Pod 1.0. Test builds don't update themselves: install this one by hand from `Pod-1.0.0-rc1.dmg`. Later releases arrive through Pod's own "Check for Updates…".

## Known issues

- **Force Quit of an app started from a Pod terminal also ends Pod's terminal sessions.** macOS force-quits everything it counts as part of that app, and Pod's terminal sessions are counted with it. Quit such apps normally (⌘Q or their Quit menu item) instead. A fix lands before 1.0.
