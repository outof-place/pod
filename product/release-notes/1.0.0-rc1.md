# Pod 1.0.0-rc1

The first release candidate for Pod 1.0. Test builds don't update themselves: install this one by hand from `Pod-1.0.0-rc1.dmg`. Later releases arrive through Pod's own "Check for Updates…".

Pod needs macOS 27 or later on a Mac with Apple silicon.

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
- **Relative links in the Markdown preview (for example `[x](docs/a.md)`) aren't clickable yet.** Only http, https and mailto links open.
