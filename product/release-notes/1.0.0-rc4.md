# Pod 1.0.0-rc4

A calmer window, native screens for most of what rc3 still sent to Pod's classic window, and a fix for terminal links that could launch an app.

From rc2 or rc3, "Check for Updates…" installs it, and Pod's terminal sessions keep running through the update. From rc1, install it by hand from `Pod-1.0.0-rc4.dmg`: drag Pod into Applications and replace the old one while Pod is still open; the old Pod quits as for an update and leaves the terminal sessions running. rc1's "Check for Updates…" can't install it, because rc2 changed the update key.

With Homebrew: `brew install --cask outof-place/tap/pod` for a new install. Installed from Homebrew at rc1, run `brew update && brew upgrade --cask --greedy pod` once; after that, "Check for Updates…" brings later releases.

Pod needs macOS 27 or later on a Mac with Apple silicon.

## Fixed

- A Command-click on a path printed in a terminal could launch what it named: an app, a `.command` file, a script. Pod now opens only documents; folders, apps and files whose default app runs or installs something are shown in Finder instead, and a path on a remote worktree is refused.
- The terminal's last row no longer hides under the bottom of the window.
- Projects show their own icon (PNG, WebP, SVG or ICO, from more places in the repo) instead of the owner's GitHub avatar. Pod does this once, on the first launch of rc4, for every GitHub avatar it did not set itself, including one you picked by hand in an earlier build; pick it again from the project's icon if you want it back.
- Icons fetched from the web are size-capped, time-limited and raster only.
- Claude's sign-in message no longer cuts off before the login's output ends.

## Changed

- **The window:** the title bar holds the tabs, one + (a click opens a terminal, ⌘T; its menu lists the agents) and one button for the right panel (Changes, History, Review, Files). The bottom status bar is gone: ports and the terminals' memory sit in the sidebar's footer, and free disk space is no longer shown. Quick Commands, the sidebar toggle and Pod Workspace live in the menus and in the ⌘J palette.
- **Agent marks:** a working agent is a small dot that breathes slowly, an agent waiting for you is a dot inside a thin ring, finished and unread is a green dot. Nothing spins any more.
- **Tabs:** resting the pointer on a tab shows its full name and its agent's state; a double-click on a terminal tab renames it.
- **Browser tabs** show the page's title and its site's icon, never the address.
- **Project groups:** make, rename, reorder, give an icon and delete groups in the sidebar.
- **Native screens** for what rc3 still opened in the classic window: Settings for everything Pod applies (agents, browser, advanced, SSH hosts, quick commands), Accounts, Plugins, Skills and browser profiles, the new worktree options, resuming and deleting sessions in Agent Session History, automations on any host, and Bitbucket, Azure DevOps and Gitea reviews.

## Known issues

- **Quitting an app that was started directly from a Pod terminal (for example by running its binary) can end all of Pod's terminal sessions about a minute later.** Start apps with `open -a <App>`, or from the Dock or Finder, instead. A fix lands before 1.0.
- **Relative links in the Markdown preview (for example `[x](docs/a.md)`) aren't clickable yet.** Only http, https and mailto links open.
